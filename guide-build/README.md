# 恋愛トリセツ（有料PDF）ビルダー

犬版「16わんこ恋愛診断」の恋愛攻略書（全32ページ）と同じ構成で、猫版のプレミアムPDFを生成します。

## トーン・デザイン方針
ターゲットが10〜20代なので、犬版の血統書調（明朝・クリーム地・ボルドー）ではなく
**カジュアルな「恋愛トリセツ」調**に振っています。
- フォント：M PLUS Rounded 1c（サイト本体と同じ丸ゴシック）
- 配色：淡いピンク地＋ラベンダー＋イエローバッジ（サイトの案Bと同系）
- 装飾：太いインク線・ハードシャドウ・角丸・絵文字
- 文体：**丁寧語（です・ます調）を維持**したまま、硬さを抜いた親しみやすい語り口。
  「〜だよね」等のタメ口は使わない。見出しだけは「サイベリアンって、こういう人」
  「LINEの送り方、これが正解」のように口語寄りで、本文は丁寧語で統一する。

## 図解方針（diagrams.py）
文字だけのページを作らないため、32ページ中22ページ（約7割）に図解を入れている。
印刷崩れしないよう、すべてインラインSVGで生成（画像fetchなし・ベクターなので拡大に強い）。

| 関数 | 図 | 使用ページ |
|---|---|---|
| svg_radar | 5角形レーダー | P4 恋愛ステータス / P20 ビッグファイブ |
| svg_flow5 | 横並びステップ | P5 5ステップ / P11 仲直り3ステップ |
| svg_flip | クセ→長所 変換 | P6 3つのクセ / P18 落とし穴 |
| svg_gauge_row | 相性の帯グラフ | P7 全16タイプ / P9 要注意3タイプ |
| svg_hbars | 横棒グラフ | P8 TOP5 / P15 相手タイプ別 |
| svg_quad | 2軸4象限マップ | P14 愛着スタイル |
| svg_compare | 左右対比バー | P16 愛の言語 |
| svg_triangle | 三角形チャート | P19 恋愛の三角理論 |
| svg_stack | 4段スタック | P21 認知機能 |
| svg_donut | ドーナツゲージ | P12 結婚向き |
| svg_timeline | 横タイムライン | P26 復縁3ステップ / P28 復縁5STEP |
| svg_vs | 左右の対比リスト | P27 執着vs愛情 / P30 SNSのする・しない |

## 使い方
```bash
pip install pillow playwright pymupdf
python3 build_guide.py ENFJ      # → guide_enfj.html
python3 topdf.py enfj            # → enfj_love_guide_cat.pdf
```

## 構成（全32ページ・7部構成）
- P1 表紙／P2 この本の使い方／P3 もくじ
- PART I 基礎編（P4-12）：恋愛人格・5段階・3つの罠・全16相性マップ・TOP5・要注意タイプ・LINE攻略・ケンカ倦怠期・結婚観
- P13 PART II 扉
- PART II 理論編（P14-21）：愛着スタイル・相手別接し方・愛の言語・あるある30・落とし穴・三角理論・ビッグファイブ・認知機能
- WORK（P22-24）：理論で自己分析・理想と現実の棚卸し・本音を伝える練習
- APPENDIX（P25-31）：仲直りフローチャート・復縁という選択／見極め／テクニック／タイプ別／SNS／SNS実践
- P32 裏表紙

## データ整合
- 相性スコアは index.html の `compatScore()` をそのまま実装（サイト表示と完全一致）
- 恋愛ステータス（★）は index.html の `PARAM` と一致
- 猫種名・性格文は `LOC.json`（index.html の LOC から抽出）

## 他タイプへの展開
`build_guide.py` 内の `C = {...}` がタイプ固有の原稿。ここを差し替えれば他15タイプを生成できる。
`guide-drafts/_datasheet.md` と `compat-matrix.md` が正データ。
